# Longevity Risk Modeling

Code for mortality-improvement modeling and longevity-risk quantification. Includes LSTM-GLM mortality forecasting, life-table construction, gender-split mortality improvement comparison, and longevity-bond pricing.

## Components
- `lstm_glm/` — LC-LSTM and LSTM-GLM mortality forecasting
- `life_tables/` — life-table construction and insurance-population preprocessing
- `longevity_bond_pricing.py` / `cashflow.py` — longevity-bond pricing and cashflow
- `mortality_improvement_by_gender.py` — gender-split mortality improvement

## Data note
Raw mortality and insurance-population data are proprietary and not included.
